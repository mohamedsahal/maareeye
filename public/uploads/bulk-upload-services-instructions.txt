Service Bulk Upload Instructions
=========================================

Please follow these instructions carefully for successful service bulk upload.

-> Do not rename or remove any columns.
-> Ensure all values are properly formatted and valid.
-> Fields like `tax_ids` must be in array format if multiple.

Column Details with Examples:
------------------------------
1. business_id         = ID of the business providing the service  
                         (Get it from Vendor Panel >> Businesses table)  
                         (e.g., 3)

2. tax_ids             = Tax ID(s) applicable to the service  
                         (Use format: ['1','2'])  
                         (e.g., ['1'])

3. unit_id             = ID of the unit used for this service  
                         (Get it from Vendor Panel >> Products >> Units table)  
                         (e.g., 5)

4. name                = Name of the service  
                         (e.g., Monthly Internet Package)

5. description         = Description of the service  
                         (e.g., High-speed internet up to 100 Mbps)

6. image               = Service image path or URL  
                         (Copy it from Vendor Panel >> Media table → click the 3rd button in Actions column to copy path)  
                         (e.g., uploads/services/service1.jpg)

7. price               = Selling price of the service (numeric)  
                         (e.g., 1500)

8. cost_price          = Cost price of the service (numeric)  
                         (e.g., 1000)

9. is_tax_included     = Whether tax is included in the price  
                         (1 = Yes, 0 = No)  
                         (e.g., 1)

10. is_recursive       = Whether the service is recurring  
                         (1 = Yes, 0 = No)  
                         (e.g., 1)

11. recurring_days     = Days between each recurrence (numeric)  
                         (Only required if `is_recursive` = 1)  
                         (e.g., 30)

12. recurring_price    = Price for each recurrence (numeric)  
                         (Only required if `is_recursive` = 1)  
                         (e.g., 1400)

13. status             = Status of the service  
                         (1 = Active, 0 = Inactive)  
                         (e.g., 1)

Notes:
---------------------------------------------------------
- All numeric fields must contain valid numbers.
- Use only numeric values for boolean fields:
    → 1 = yes / true / active  
    → 0 = no / false / inactive
- If the service is not recurring, you can leave `recurring_days` and `recurring_price` empty or set to 0.
- Ensure all referenced IDs (business, tax, unit) exist in the system.
- Image must be uploaded in advance; then copy the image path from the media table as instructed.
