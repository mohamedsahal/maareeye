Delivery Boy Bulk Upload Instructions
=========================================

Please follow these instructions carefully for successful delivery boy bulk upload.

-> Do not rename or remove any columns.
-> Ensure all values are properly formatted and valid.
-> The `permissions` field must be passed as a JSON array format.

Column Details with Examples:
------------------------------
1. name          = Full name of the delivery boy  
                   (e.g., Raj Kumar)

2. email         = Email address  
                   (e.g., raj@example.com)

3. phone         = Mobile number  
                   (10-digit number only)  
                   (e.g., 9876543210)

4. password      = Login password  
                   (e.g., raj@123)

5. business_id   = ID of the business the delivery boy belongs to  
                   (Get it from Vendor Panel >> Businesses table)  
                   (e.g., 3)

6. permissions   = JSON array of allowed permissions  
                   (use this only, {"customer_permission":"1","transaction_permission":"1","orders_permission":"1"})

7. status        = Status of the delivery boy (1 = active, 0 = inactive)  
                   (e.g., 1)


Notes:
---------------------------------------------------------
- `phone` must be a valid 10-digit number (digits only).
- `email` must be in a valid email format.
- `password` must be strong and secure.
- Use only numeric values for `status`:
    → 1 = active  
    → 0 = inactive
- `permissions` must be a valid JSON array (enclose in double quotes if using CSV format).
- Ensure `business_id` exists and is valid.
