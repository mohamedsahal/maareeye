Product Bulk Upload Instructions
=========================================

Please follow these instructions carefully for successful product bulk upload.

-> Do not rename or remove any columns.
-> Ensure all values are properly formatted and valid.
-> You can add multiple variants and define their stock for multiple warehouses.

Column Details with Examples:
------------------------------
1. category_id                      = ID of the product category  
                                      (Get from Vendor Panel >> Products >> Categories table)  
                                      (e.g., 10)

2. business_id                      = ID of the business  
                                      (Get from Vendor Panel >> Businesses table)  
                                      (e.g., 3)

3. product_name                     = Name of the product  
                                      (e.g., Apple iPhone 13)

4. description                      = Description of the product  
                                      (e.g., 128GB, Blue, 5G)

5. tax_ids                          = Tax IDs applicable (array format)  
                                      (e.g., ['1','2'])

6. brand_id                         = ID of the brand  
                                      (Get from Vendor Panel >> Products >> Brands table)  
                                      (e.g., 4)

7. image                            = Image path of the product  
                                      (Copy from Vendor Panel >> Media table → 3rd button in Actions)  
                                      (e.g., uploads/products/iphone13.jpg)

8. product_type                     = Type of product  
                                      (Use: single or variable)  
                                      (e.g., variable)

9. stock_management                = Enable stock management (0 = disabled, 1 = product level, 2 = variable level)  
                                      (e.g., 1)

10. product_stock                   = Total stock (Only if stock management is product level)  
                                      (e.g., 100)

11. product_qty_alert               = Low stock alert threshold (Only if stock management is product level)  
                                      (e.g., 10)

12. product_unit_id                 = Unit ID of the product (Only if stock management is product level)
				      (Get from Vendor Panel >> Products >> Units table)  
                                      (e.g., 1)

13. is_tax_included                 = Whether price includes tax (1 = yes, 0 = no)  
                                      (e.g., 1)

14. status                          = Product status (1 = active, 0 = inactive)  
                                      (e.g., 1)

Variant 1 Details:
------------------------------
15. variant_1_name                  = Name of Variant 1 (e.g., 128GB Blue)

16. variant_1_barcode              = Barcode for Variant 1 (e.g., 1234567890123)

17. variant_1_sale_price           = Sale price for Variant 1 (e.g., 70000)

18. variant_1_purchase_price       = Purchase price for Variant 1 (e.g., 65000)

19. variant_1_unit_id              = Unit ID for Variant 1 (e.g., 1) (Only if stock management is variable level)  

20. variant_1_stock                = Total stock for Variant 1 (e.g., 50) (Only if stock management is variable level)

21. variant_1_qty_alert            = Low stock alert for Variant 1 (e.g., 5) (Only if stock management is variable level)

22. variant_1_warehouse_1_id       = Warehouse ID 1 (e.g., 1)
				     (Get it from Vendor Panel >> Warehouses table) 

23. variant_1_warehouse_1_stock    = Stock in Warehouse 1 (e.g., 30)

24. variant_1_warehouse_1_qty_alert= Low stock alert in Warehouse 1 (e.g., 3)

25. variant_1_warehouse_2_id       = Warehouse ID 2 (e.g., 2)

26. variant_1_warehouse_2_stock    = Stock in Warehouse 2 (e.g., 20)

27. variant_1_warehouse_2_qty_alert= Low stock alert in Warehouse 2 (e.g., 2)

Variant 2 Details (if applicable):
------------------------------
28. variant_2_name                  = Name of Variant 2 (e.g., 256GB Black)

29. variant_2_barcode              = Barcode for Variant 2 (e.g., 9876543210987)

30. variant_2_sale_price           = Sale price for Variant 2 (e.g., 80000)

31. variant_2_purchase_price       = Purchase price for Variant 2 (e.g., 75000)

32. variant_2_unit_id              = Unit ID for Variant 2 (e.g., 1) (Only if stock management is variable level)

33. variant_2_stock                = Total stock for Variant 2 (e.g., 60) (Only if stock management is variable level)

34. variant_2_qty_alert            = Low stock alert for Variant 2 (e.g., 6) (Only if stock management is variable level)

35. variant_2_warehouse_1_id       = Warehouse ID 1 (e.g., 1)
				     (Get it from Vendor Panel >> Warehouses table)

36. variant_2_warehouse_1_stock    = Stock in Warehouse 1 (e.g., 35)

37. variant_2_warehouse_1_qty_alert= Low stock alert in Warehouse 1 (e.g., 3)

38. variant_2_warehouse_2_id       = Warehouse ID 2 (e.g., 2)
			             (Get it from Vendor Panel >> Warehouses table)		

39. variant_2_warehouse_2_stock    = Stock in Warehouse 2 (e.g., 25)

40. variant_2_warehouse_2_qty_alert= Low stock alert in Warehouse 2 (e.g., 3)

Notes:
---------------------------------------------------------
- All IDs must be valid and exist in the system (category, brand, business, unit, warehouse).
- Use `product_type = single` for products without variants; leave variant columns blank.
- Image must be uploaded in advance; get the path from the Media table.
- Use only numeric values for boolean fields:
    → 1 = yes / active  
    → 0 = no / inactive
