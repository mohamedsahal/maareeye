Customer Bulk Update Instructions
=========================================

Please follow these instructions carefully for successful customer bulk update.

-> Do not rename or remove any columns.
-> Ensure all values are properly formatted and valid.
-> The `id` field is mandatory and must match an existing customer ID.

Column Details with Examples:
------------------------------
1. id            = ID of the customer to be updated  
                   (Get it from Vendor Panel >> Customers table)  
                   (e.g., 15)

2. name          = Full name of the customer  
                   (e.g., John Doe)

3. email         = Customer's email address  
                   (e.g., john@example.com)

4. phone         = Customer's mobile number  
                   (10-digit number only)  
                   (e.g., 9876543210)

5. password      = Login password for the customer account  
                   (e.g., john@123)

6. business_id   = ID of the business the customer belongs to  
                   (Get it from Vendor Panel >> Businesses table)  
                   (e.g., 3)

7. address       = Customer's address  
                   (e.g., 123 Main Street, New York)

8. status        = Status of the customer (1 = active, 0 = inactive)  
                   (e.g., 1)


Notes:
---------------------------------------------------------
- `id` is required for updating and must match a valid existing customer.
- `phone` must be a valid 10-digit number (digits only).
- `email` must be in a valid email format.
- Use only numeric values for `status`:
    → 1 = active  
    → 0 = inactive
- Make sure `business_id` exists in the system.
