Category Bulk Update Instructions
=========================================

Please follow these instructions carefully for successful category bulk update.

-> Do not rename or remove any columns.
-> Ensure all values are properly formatted and valid.
-> The `id` field is mandatory and must match an existing category.
-> Use `0` in `parent_id` if it's a main (top-level) category.

Column Details with Examples:
------------------------------
1. id            = ID of the category to be updated  
                   (Get it from Vendor Panel >> Products >> Categories table)  
                   (e.g., 10)

2. parent_id     = ID of the parent category  
                   (Pass 0 if it's a main category)  
                   (e.g., 0 or 5)

3. name          = Name of the category  
                   (e.g., Electronics)

4. status        = Status of the category (1 = active, 0 = inactive)  
                   (e.g., 1)

Example Row:
---------------------------------------------------------
10	0	Electronics	1

Notes:
---------------------------------------------------------
- `id` is required and must match a valid existing category ID.
- Use `0` for `parent_id` if the category is a root (main) category.
- Use only numeric values for `status`:
    → 1 = active  
    → 0 = inactive
- Make sure `parent_id` (if not 0) exists in the system and is active.
