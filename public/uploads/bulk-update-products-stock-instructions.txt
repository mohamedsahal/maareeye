Product Stock Update Instructions
=========================================

Please follow these instructions carefully for successful stock update of product variants.

-> Do not rename or remove any columns.
-> Ensure all values are properly formatted and valid.
-> Each row updates stock for a specific product variant in a specific warehouse.

Column Details with Examples:
------------------------------
1. variant_id         = ID of the product variant to update stock for  
                         (Get it from Vendor Panel >> Products → click eye icon → Variant table)  
                         (e.g., 102)

2. stock_management   = Whether stock management is enabled for this variant  
                         (1 = product level stock management, 2 = variable level stock management)  
                         (e.g., 1)

3. warehouse_id       = ID of the warehouse where stock is being updated  
                         (Get it from Vendor Panel >> Warehouses table)  
                         (e.g., 3)

4. current_stock      = Current total stock available in the selected warehouse (numeric)  
                         (e.g., 50)

5. quantity           = Quantity to be added or removed (numeric)  
                         (e.g., 10)

6. type               = Type of stock update  
                         (Use one of: add, subtract)  
                         (e.g., add)

7. note               = Any comment or note related to the stock update (optional)  
                         (e.g., Restocked 10 units)


Notes:
---------------------------------------------------------
- `variant_id` must be valid and exist in the system.
- `warehouse_id` must match an existing warehouse.
- `stock_management`:
    → 1 = enabled  
    → 0 = disabled
- `type` must be either:
    → add (to increase stock)  
    → reduce (to decrease stock)
- `quantity` and `current_stock` must be numeric.
