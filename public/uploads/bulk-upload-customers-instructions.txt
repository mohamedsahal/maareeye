Customer Bulk Upload Instructions
=========================================

Please follow these instructions carefully for successful customer bulk upload.

-> Do not rename or remove any columns.
-> Ensure all values are properly formatted and valid.

Column Details with Examples:
------------------------------
1. name          = Full name of the customer  
                   (e.g., John Doe)

2. email         = Customer's email address  
                   (e.g., john@example.com)

3. phone         = Customer's mobile number  
                   (10-digit number only)  
                   (e.g., 9876543210)

4. password      = Login password for the customer account  
                   (e.g., john@123)

5. business_id   = ID of the business the customer belongs to  
                   (Get it from Vendor Panel >> Businesses table)  
                   (e.g., 3)

6. address       = Customer's address  
                   (e.g., 123 Main Street, New York)

7. status        = Status of the customer (1 = active, 0 = inactive)  
                   (e.g., 1)

Notes:
---------------------------------------------------------
- `phone` must be a valid 10-digit number (digits only).
- `email` must be in a valid email format.
- Use only numeric values for `status`:
    → 1 = active  
    → 0 = inactive
- Make sure `business_id` is valid and exists in the system.
